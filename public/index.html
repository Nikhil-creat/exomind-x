Pipeline 5 stages

From photons
to verdicts.

01

Async ingestion

Kepler DR24 TCEs, GroupShuffleSplit by kepid (80/10/10), lightkurve stitching, transit-masked flatten(401), parquet cache.

02

Dual-view folding

2,001-bin global and 201-bin local views, median flux 0, deepest point −1, plus period, duration, depth metadata.

03

ExoNet-V2 + baseline

Dual 1D-CNN branches with BatchNorm, MaxPool, Dropout vs a HistGradientBoosting baseline. MLflow + ONNX export.

04

Agent graph + RAG

Ingestion → Classifier → Diagnostic → RAG. Hybrid dense + BM25 retrieval with reciprocal rank fusion over NASA ADS/arXiv.

05

Active learning

Entropy sampler routes 0.45 ≤ P ≤ 0.55 into a Redis HITL queue for expert labels, then retrains.

06

Secure serving

FastAPI, token-bucket limiter, OAuth2-ready, OpenTelemetry traces, Prometheus /metrics, non-root Docker.

Architecture end-to-end

One graph.
Six layers.

Leakage-proof

Autovetter columns are rejected and splits are grouped by kepid, so no star appears in both train and test.

Uncertainty-aware

Anything in 0.40 ≤ P ≤ 0.65, or where CNN and baseline disagree, escalates to the agent graph.

Human in the loop

0.45 ≤ P ≤ 0.55 goes to an expert queue; labels feed the next retrain.

Is the classifier trained?

Not yet in the live demo. The repo ships the architecture, training reference and a heuristic scorer so the full pipeline is testable end to end.

How is data leakage prevented?

Autovetter predictions are dropped from features and splits are grouped by star ID.

Can I self-host it?

Yes: a non-root multi-stage Dockerfile and Render blueprint are included, plus Vercel config.
